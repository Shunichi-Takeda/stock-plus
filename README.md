# Stock Plus

## 概要

[Stock](https://www.stock-app.jp/)（情報ストックツール）をブラウザ上で拡張するChrome拡張ツールキットです。

Stock本体には無い便利機能を、ページに後付けで追加します。機能は独立したモジュール（feature）として実装されており、今後のアップデートでメッセージ機能以外の拡張も同じ枠組みで追加していけます。

## できるようになること

- **返信済みメッセージトラッキング**
  - 送信操作（送信ボタン / Enter / Cmd+Enter / Ctrl+Enter）と「了解しました」ボタンの自動検知
  - メッセージ一覧への「✓ 返答済み」バッジ表示
  - メッセージ一覧のタブ行に「**返信済み**」の一覧（フィルタ）を追加
  - 同じく「**@me**」の一覧（フィルタ）を追加（自分宛メンションのあるメッセージを開くと記録）
  - 記録はlocalStorageのみに保存され、30日で自動削除（外部送信なし）
- **チャット詳細画面のピン留めボタン**
  - 一覧にあるピン留めを、開いているチャットウィンドウのヘッダーからも切り替え可能に
- **テンプレート一覧の絞り込みフィルタ**
  - ノート作成時の「テンプレート一覧」に、テンプレート名で絞り込むテキストフィールドを追加
- **全員に返信（メンション引き継ぎ）**
  - 「返信」ボタン押下時に、元メッセージ内の全メンションを入力欄へ追記（自分宛は除外。Gmailの「全員に返信」相当）
- **機能ごとのON/OFF設定**
  - ツールバーのStock Plusアイコンをクリックすると設定ダイアログが開き、各機能を個別にON/OFFできます（デフォルトはすべてON。変更は開いているStockタブへ即時反映）

## 導入の仕方

コマンド操作は不要です。ZIPをダウンロードして展開し、Chromeに読み込むだけで使えます（所要3分程度）。

> Chrome ウェブストアには公開していないため、「デベロッパーモード」での読み込みになります。Chrome / Microsoft Edge で利用できます。

### 1. ZIPをダウンロードする

1. [リリース一覧](https://github.com/Shunichi-Takeda/stock-plus/releases) を開きます
2. 一番上（最新）のリリースの **Assets** を開き、**Source code (zip)** をクリックします
   - [最新版を直接ダウンロード](https://github.com/Shunichi-Takeda/stock-plus/releases/latest) からでもOKです

### 2. ZIPを展開して、置き場所を決める

1. ダウンロードしたZIP（例: `stock-plus-0.11.0.zip`）をダブルクリックして展開します
   - macOS: ダブルクリックで同じ場所にフォルダができます
   - Windows: 右クリック →「すべて展開」
2. できたフォルダ（例: `stock-plus-0.11.0`）を、**ずっと置いておける場所**に移動します
   - 例: `書類（Documents）/stock-plus-0.11.0`
   - ⚠️ **このフォルダは削除・移動しないでください。** Chromeは読み込んだフォルダを直接参照し続けるため、消すと拡張機能が動かなくなります（ダウンロードフォルダのままにしておくと、掃除で消してしまいがちなので注意）

### 3. Chromeに読み込む

1. Chromeのアドレスバーに `chrome://extensions` と入力して開きます
2. 右上の「**デベロッパーモード**」をONにします
3. 左上の「**パッケージ化されていない拡張機能を読み込む**」をクリックします
4. 手順2で移動したフォルダ（`manifest.json` が直接入っているフォルダ）を選択します
   - フォルダの中を開くと `manifest.json` が見えるはずです。開いた先にもう一段フォルダがある場合は、**その内側のフォルダ**を選んでください
5. 一覧に「Stock Plus」が表示されれば完了です

### 4. 使い始める

Stock（stock-app.jp）を開きます。**すでに開いている場合はタブをリロード**してください。

以降、Stockのメッセージで返信すると自動的に記録が始まります。
ツールバーのStock Plusアイコン（パズルピースのアイコンの中にあります。ピン留めしておくと便利です）から、機能ごとのON/OFFを切り替えられます。

### アップデートの反映

リリースタグは都度更新しています。新しいバージョンが出たら、以下の手順で入れ替えてください。

1. 手順1〜2と同じように、新しいZIPをダウンロードして展開・移動します
2. `chrome://extensions` を開き、古い「Stock Plus」の「**削除**」をクリックします
3. 「**パッケージ化されていない拡張機能を読み込む**」で、新しいフォルダを選択します
4. Stockのタブをリロードします
5. 古いフォルダは削除して構いません

> 📌 返信済み・@meの記録はブラウザ側（Stockのページ）に残るため、入れ替えても消えません。
> 機能のON/OFF設定は初期値（すべてON）に戻るため、変更していた場合は設定し直してください。
> 設定も引き継ぎたい場合は、**フォルダ名と置き場所を前回と完全に同じにして中身だけ差し替え**、`chrome://extensions` の Stock Plus の再読み込み（🔄）を押してください。

### 開発者向け（gitが使える方）

```bash
git clone git@github.com:Shunichi-Takeda/stock-plus.git
```

以降は手順3と同じです。更新は `git pull` のあと、`chrome://extensions` で Stock Plus の再読み込み（🔄）を行い、**Stockのタブもリロード**してください。この方法なら拡張機能のIDが変わらないため、ON/OFF設定も維持されます。

## ディレクトリ構成

```
stock-plus/
├── manifest.json              # Manifest V3
└── src/
    ├── content.js             # エントリポイント（全featureを起動）
    ├── core/
    │   ├── storage.js         # TTL付きlocalStorageラッパー（既定30日）
    │   └── featureManager.js  # feature登録・起動、インスタンスガード
    ├── features/
    │   └── repliedMessages.js # 返信済みトラッキング機能
    └── styles/
        └── stock-plus.css
```

## 新しい機能の追加方法

1. `src/features/` に新しいJSファイルを作成し、以下の形で登録します

   ```js
   window.StockPlus.registerFeature({
     id: "my-new-feature",
     name: "新機能の説明",
     init() { /* 初期化処理 */ },
   });
   ```

2. `manifest.json` の `content_scripts.js` に、`src/content.js` より **前** の位置でファイルパスを追加します

## 注意事項・チューニング

- DOMセレクタは実際のStockのDOM（2026-08時点で実機確認済み）に合わせています。
  Stock側のDOM変更時は `src/features/repliedMessages.js` 冒頭の `SELECTORS` だけ直せば追従できます
- スレッドの識別は宛先名ベースです（Stock側にスレッドIDやURLが存在しないため）。
  照合キーで多少の改名には追従しますが、タイトルを大きく変更すると過去の記録とは別扱いになります
- 記録の全削除は、返信済みフィルタ使用中に確認できる記録をリセットしたい場合に
  DevToolsから `localStorage.removeItem('stockPlus.repliedMessages')` で行えます
